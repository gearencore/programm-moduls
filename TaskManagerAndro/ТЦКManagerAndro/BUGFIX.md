# BUGFIX — Task Manager

1. **Логика приложения находилась в Interface.** CRUD, выбор задачи и сохранение перенесены в отдельный класс TaskManager; Interface отвечает за Tkinter.
2. **JSON записывался напрямую.** StorageManager теперь записывает во временный файл и заменяет оригинал после успешной записи, чтобы снизить риск повреждения данных.
3. **Старый формат задач не содержал всех полей.** Task.from_dict() загружает строки и словари с `content`, сохраняя название и текст. Новые поля получают значения по умолчанию.
4. **После обновления списка пропадало выделение.** Выбранная задача восстанавливается по постоянному ID после редактирования и смены статуса.
5. **Удаление происходило без подтверждения.** Добавлен запрос подтверждения перед удалением.
6. **Учебные и неиспользуемые файлы смешивались с приложением.** Из релизного архива исключены калькулятор, отдельные примеры, кэш и лишние копии ресурсов.

Тесты: проверка синтаксиса; CRUD и перезагрузка JSON; миграция старых данных; создание и работа окна в виртуальном дисплее. На Windows отдельно не запускалось.
