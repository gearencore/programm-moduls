# BUGFIX — Task Manager

## Исправлено в уроке 13–14

1. **`src/view.py`: неопределённая переменная `root`.** Прежний модуль создавал виджеты при импорте и обращался к `root` до его создания. Теперь он определяет `TaskView` и создаёт виджеты только после передачи существующего окна.
2. **`src/storege.py`: ошибочное имя модуля.** Код хранения перенесён в `src/storage.py`; графический интерфейс использует его функции `load_tasks()` и `save_tasks()`.
3. **Логика и оформление были перемешаны в `ui/Interface.py`.** Создание виджетов вынесено в `view.py`, а управление задачами осталось в `Interface`.
4. **Отсутствовали требуемые виджеты.** Созданы `ui/AppListbox.py` и `ui/AppLabel.py`; список обновляется методом `show_tasks()`.
5. **Ошибки чтения JSON могли быть неочевидными.** Неверный формат файла теперь вызывает понятное сообщение, а не молчаливое игнорирование содержимого.

## Известные ограничения

- Добавлен редактор названия и содержимого задачи с сохранением изменений. Старый формат списка строк в JSON поддерживается.
- Для запуска окна необходим Tkinter и графический рабочий стол.
- Вспомогательные учебные примеры (`oop/`, `proceses.py`, `test.py`, `src/cal.py`) не изменялись, поскольку не относятся к заданию.
