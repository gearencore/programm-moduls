# Task Manager

Учебный менеджер задач на Python с графическим интерфейсом Tkinter.

## Запуск

Из корня проекта:

```bash
python src/main.py
```

Требуется Python с установленным Tkinter; дополнительные библиотеки для основного приложения не нужны.

## Работа с задачами

Введите название задачи и её содержимое в многострочном поле, затем нажмите **Добавить**. Чтобы изменить запись, выберите её в списке, поправьте название или содержимое и нажмите **Сохранить изменения**. Кнопка **Удалить** удаляет выбранную запись, **Очистить** очищает поля редактора. Все изменения сохраняются в `src/task.json` в формате JSON. Старые записи в виде строк загружаются автоматически.

## Структура

- `src/main.py` — запуск программы.
- `src/ui/Interface.py` — класс `Interface`, главное окно и действия пользователя.
- `src/view.py` — расположение элементов и отображение задач.
- `src/storage.py` — загрузка и сохранение JSON.
- `src/ui/Button.py` — собственный `AppButton`.
- `src/ui/AppLabel.py` — собственный `AppLabel`.
- `src/ui/AppListbox.py` — собственный `AppListbox`.
- `BACKLOG.md` — выполненные пункты и возможные дальнейшие улучшения.
- `BUGFIX.md` — найденные и исправленные проблемы.

Другие файлы в архиве — вспомогательные учебные примеры.
