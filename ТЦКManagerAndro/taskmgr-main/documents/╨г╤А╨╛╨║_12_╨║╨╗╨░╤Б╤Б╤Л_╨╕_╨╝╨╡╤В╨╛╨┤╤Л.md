# Урок 12. Классы и методы

Класс в Python описывает объект и его поведение. Методом называется функция, объявленная внутри класса. Метод `__init__()` запускается при создании объекта и задаёт его начальные свойства.

В проекте Task Manager класс `Interface` находится в файле `src/ui/Interface.py`. При создании объекта класса метод `__init__()` создаёт главное окно `root`, задаёт заголовок, размер и цвет, а затем вызывает методы создания интерфейса и загрузки задач.

Методы `add_task()`, `delete_task()`, `load_tasks()` и `save_tasks()` отвечают за добавление, удаление, загрузку и сохранение задач. Это позволяет хранить код приложения в одном классе и разделять действия на небольшие понятные методы.
